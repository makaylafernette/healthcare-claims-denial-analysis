# Project Overview

## Project Title
Healthcare Insurance Claims Denial & Appeals Analysis

## Project Objective
Analyze publicly available 2024 healthcare insurance
claims data to investigate denial patterns and appeal
outcomes, comparing Michigan with national results

## Data Source
Centers for Medicare & Medicaid Services (CMS)

## Reporting Year
2024

## Geographic Focus
Michigan and United States

## Tools

- SQL
- Power BI
- Github
